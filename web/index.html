Organize into Jellyfin folders

This is the one part of the app that changes files on disk — always from a preview, always undoable. Preview first — nothing moves until you press Apply. Every organize can be undone.

Movies become Title (Year)/Title (Year).ext; episodes become Series/Season 01/Series - S01E01 - Episode Title.ext (Season 00 for specials, S01E01-E02 for multi-episode files). Subtitles, .nfo files and folder artwork travel with their video. Anything the app can't identify stays exactly where it is and is listed under the plan; name collisions are flagged and never overwritten. Scanning stays read-only — only this tab changes files, and only in the ways the chosen mode describes.

Mode:

Build link library creates a clean Jellyfin folder tree in the target folder and fills it with hardlinks to the source files. The originals stay exactly where they are, so existing paths — including seeding paths — keep working.

A hardlink is another name for the same file, not a copy. The source and target must be on the same filesystem or volume.

Editing the file through either name edits the same shared content. Deleting the original name does not free the file's space while a link remains; the space is freed only when the last name for that file is deleted.

Apply creates folders and links only. It never moves, renames, copies, deletes, or edits an original.

After a preview, Export problems (JSON) downloads one file listing everything that could not be linked — every collision, unidentified and unlinkable file, with the reasons and the evidence behind each — so naming problems can be diagnosed in bulk.

Automation

Scan automatically on a schedule

Set one or the other — when both are set, the interval wins. A scan that comes due while another scan or a file operation is running is skipped and recorded, never queued. Missed schedules never stack: after downtime, one catch-up scan runs. Applies when you save; the app must be running for scans to fire.

POST a summary when a scan finishes

Fires on completion — and on failure, labeled as such; cancelled scans stay silent. The payload carries counts only: no file paths, no credentials. Delivery is fire-and-forget: a dead endpoint can never slow down or fail a scan. Treat the URL itself like a password (Discord/ntfy URLs embed one).

OpenSubtitles (optional)

Download missing subtitles from OpenSubtitles from the Subtitles wizard (Step F → Download). This uses your own OpenSubtitles account: create a free API key on their site and paste it here. Search needs only the key; downloads follow their login-first flow, so they also need your account username + password. Downloads count against your account's quota — the wizard shows the remaining number the API itself reports, never a hardcoded one. Credentials are stored in opensubtitles.json (owner-only permissions) in the app's data folder and are never sent back to this page.

Enable OpenSubtitles

Leaving a credential field blank keeps the stored value. Forget credentials erases all three.

Plex (optional)

Connect a Plex Media Server to import your library folders as scan roots and to cross-check Plex items against the disk (Health tab). The easiest way is Sign in with Plex: click it, approve on Plex's own page — you're already signed in there, it's one click — and the app finds your servers. No token hunting. Every file tool in this app works without Plex connected — this only saves typing paths. The connected server's token is stored in plex.json in the app's data folder; treat that file like a password. Your Plex account sign-in is kept only in memory — enough to switch servers while the app runs — unless you tick remember my sign-in when picking a server, which stores the account token in that same file so switching also survives restarts.

Advanced: manual connection (URL + token)

For unclaimed or local-only servers that can't use the plex.tv sign-in. The address may be typed with or without http:// — it's added when missing. Test connection checks what's typed here, even before you save; saving runs the test too, so you know immediately whether it worked.

Only needed when Plex and this app live on different machines (e.g. Plex on Ultra, app on Windows). Applies however you connected. Longest matching prefix wins.
