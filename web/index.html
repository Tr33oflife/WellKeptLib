Organize into Jellyfin folders

This is the one part of the app that changes files on disk — always from a preview, always undoable. Preview first — nothing moves until you press Apply. Every organize can be undone.

Movies become Title (Year)/Title (Year).ext; episodes become Series/Season 01/Series - S01E01 - Episode Title.ext (Season 00 for specials, S01E01-E02 for multi-episode files). Subtitles, .nfo files and folder artwork travel with their video. Anything the app can't identify stays exactly where it is and is listed under the plan; name collisions are flagged and never overwritten. Scanning stays read-only — only this tab moves files, and only inside the folder you pick.

Plex (optional)

Connect a Plex Media Server to import your library folders as scan roots and to cross-check Plex items against the disk (Health tab). The easiest way is Sign in with Plex: click it, approve on Plex's own page — you're already signed in there, it's one click — and the app finds your servers. No token hunting. Every file tool in this app works without Plex connected — this only saves typing paths. The connected server's token is stored in plex.json in the app's data folder; treat that file like a password. Your Plex account sign-in is kept only in memory — enough to switch servers while the app runs — unless you tick remember my sign-in when picking a server, which stores the account token in that same file so switching also survives restarts.

Advanced: manual connection (URL + token)

For unclaimed or local-only servers that can't use the plex.tv sign-in. The address may be typed with or without http:// — it's added when missing. Test connection checks what's typed here, even before you save; saving runs the test too, so you know immediately whether it worked.

Only needed when Plex and this app live on different machines (e.g. Plex on Ultra, app on Windows). Applies however you connected. Longest matching prefix wins.
